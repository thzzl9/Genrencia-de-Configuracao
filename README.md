## 🛠️ O que foi feito:
1. **Criação do Repositório:** Configurado como público, contendo este `README.md` e o `.gitignore` para Java.
2. **Convite de Colaborador:** O colega foi adicionado ao projeto para trabalharmos juntos.
3. **Código Java:** Criado e commitado diretamente pelo navegador usando o editor GitHub.dev.
4. **Trabalho com Branches:** Cada aluno criou uma branch separada para alterar o código.
5. **Pull Request e Merge:** As alterações foram revisadas pelo colega e unificadas na branch principal (`main`).
